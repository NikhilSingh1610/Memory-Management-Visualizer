 Overview

OSLab is an educational simulator that visually demonstrates how operating systems manage memory.
It breaks down complex OS concepts into simple animations and step-by-step visual flows.

This tool is especially useful for:

📘 B.Tech: OS labs

📘 Vitualizing the memory management techniques.

🎓 Exam preparation

🧪 Demonstrating paging & segmentation

🧠 Building intuition about memory allocation and page faults

📚 Features at a Glance

🔹 Paging Simulation

Page tables for each process

Frame allocation & deallocation

Page hit / page fault visualization

FIFO & LRU page replacement

Clean display of memory state after each access

🔹 Segmentation Simulation

Allocate variable-sized segments

Segment tables with base & limit

Logical to physical address translation

Automatic segmentation-fault detection

🔹 Virtual Memory Simulation

Virtual address → page + offset

Page-in / page-out simulation

Integration with user-selected replacement algorithms

Frame view updated live

🔹 Simple, User-Friendly UI

Runs entirely on the web

No software to install

Smooth animations & real-time updates

Designed for both beginners and advanced learners

🧠 What You Will Learn

How paging divides logical memory into fixed-size pages

Why and when page faults occur

How replacement algorithms decide which page to evict

How segmentation translates addresses

How virtual memory extends RAM using disk

 OSLab helps visualize what textbooks can only explain with diagrams.
